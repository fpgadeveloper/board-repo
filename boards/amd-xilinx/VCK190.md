## Notes

VADJ_FMC supports 1.2 V / 1.5 V (discrete values; default 1.5 V, shared by both FMC+ slots). Set at boot by the ZU4 System Controller per ANSI/VITA 57.4 IPMI: it reads each attached FMC card's IIC EEPROM and picks a voltage supported by both board and card (1.5 V with no card attached; 0 V if no valid IPMI data is found). The System Controller UI (`FMC > Set VADJ`) can override the IPMI routine with an explicit value.
