## Notes

VADJ_FMC supports 1.2 V / 1.5 V (discrete values; default 1.5 V, rail set to 0 V if no compatible voltage is found). Set at boot by the ZU4 System Controller (XCZU4) per ANSI/VITA 57.4 after reading the FMC card's IPMI EEPROM; the system controller user interface allows the IPMI routine to be overridden with an explicit value.
