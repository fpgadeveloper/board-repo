## Notes

VADJ_FMC supports 1.2 V / 1.5 V (discrete values; default 1.5 V — Versal HBM XPIO banks do not support 1.8 V). Set at boot by the ZU4 system controller per ANSI/VITA 57.4 IPMI: with no card fitted the rail is set to 1.5 V; with a card fitted its IPMI EEPROM is read to pick a mutually supported voltage, and the rail is set to 0 V if no valid match is found. The system controller UI can override the IPMI routine with an explicit value.
