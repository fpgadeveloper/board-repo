## Notes

VADJ_FMC supports 1.2 V / 1.5 V / 1.8 V (discrete values; 1.8 V when no FMC card is attached). Set at boot by the MSP430 System Controller (U38), which reads the FMC card's IPMI EEPROM to pick a voltage supported by both board and module (0 V if no valid IPMI data); the System Controller UI can override with an explicit value.
