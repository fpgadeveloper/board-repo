## Notes

The FMC VADJ pins are unpowered out of the box — resistors R140–R143 (0R, not assembled) must be fitted to connect the 3V3_FMC rail to the connector's VADJ pins. 3V3_FMC defaults to 3.3 V and is adjusted with trimmer potentiometer VR1 (or replaced by an external supply on header PT4) to match the daughter card (e.g. 1.2 / 1.5 / 1.8 V); the FMC bank VCCIO must be set to the same voltage via jumpers J10–J13. There is no auto-negotiation — the board does not read the FMC IPMI EEPROM.
