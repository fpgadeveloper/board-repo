## Notes

VADJ (rail `1V8_FMC`) defaults to 1.8 V, set by the pin-strap resistor network of a
TPS542A50 regulator; a 25 kΩ trimmer (VR1) in the strap network gives continuous
hardware adjustment, with documented set points of 1.8 V and 1.2 V (the FMC-facing
FPGA bank's VCCIO is on the same rail). Header PJ4 enables the regulator's I2C
programming mode and J7 accepts an external bench supply for the rail — but there is
no system controller and the board does not read the FMC card's IPMI EEPROM, so any
VADJ change is manual.
